## 🚀 在您的 Mac 上使用

### 第一步：确认 Scrapling 已安装

您之前已经安装过了，但可以再确认：

```bash
# 检查是否已安装
python3 -c "import scrapling; print('Scrapling version:', scrapling.__version__)"

# 如果还没安装
pip3 install "scrapling[all]>=0.4.8"
```

### 第二步：下载脚本到您的 Mac

把 `agent-skill/Scrapling-Skill/` 文件夹复制到您的 Mac。

### 第三步：先做个快速测试

在您的 Mac 终端：

```bash
cd /path/to/Scrapling-Skill
python3 quick_test.py
```

这会爬取第1页，确认一切正常工作。

### 第四步：运行完整爬虫

修改 `scrape_movies.py` 中的配置（可选）：

```python
# 在文件顶部修改
PAGES_TO_SCRAPE = 10      # 爬取10页（或改成您想要的页数）
CONCURRENT_REQUESTS = 5   # 并发数，可根据网络调整
USE_STEALTH_MODE = False  # 简单HTTP模式就足够了
```

然后运行：

```bash
python3 scrape_movies.py
```

## 🔧 高级配置

### 如果需要更强的反爬虫能力

如果网站有防护，可以改成 stealth 模式：

```python
USE_STEALTH_MODE = True  # 在 scrape_movies.py 中
```

但需要先安装浏览器驱动：
```bash
scrapling install --force
```

### 调整爬取页数

```python
PAGES_TO_SCRAPE = 5  # 改成您想要的页数
```

### 调整并发数

```python
CONCURRENT_REQUESTS = 3  # 慢一点但更稳定
```

## ⚠️ 注意事项

1. **合规使用** - 只爬取公开数据，遵守网站规则
2. **合理频率** - 不要给网站造成过大压力
3. **隐私保护** - 不爬取个人敏感信息
4. **数据用途** - 仅用于学习/研究目的

## 🆘 故障排除

### 问题：连接超时

**解决：** 增加超时时间或减少并发数

### 问题：找不到元素

**解决：** 检查网站结构是否有变化，可能需要调整 CSS 选择器

### 问题：数据解析错误

**解决：** 查看 `quick_test.py` 中的简单版本，它更稳定
